# Остров

Приложение «жизнь как долгая игра»: сезоны по 12 недель, квесты с планом «если — то», 3D-остров, который растёт годами, и летопись, которая с каждым годом становится ценнее. Устанавливается на телефон как PWA и работает без интернета.

**Открыть:** https://adil3akarin-blip.github.io/ostrov/

## Как открыть на компьютере

```bash
python3 -m http.server 4321
```

Потом открой http://localhost:4321. Двойной клик по `index.html` тоже работает, но тогда three.js грузится с CDN.

На localhost офлайн-режим выключен, чтобы правки сразу были видны. Включить его для проверки: http://localhost:4321/?sw

## Как поставить на телефон

Офлайн-режим и установка работают только по **https**, поэтому папку нужно выложить на хостинг. Сборка не нужна: это статические файлы.

- **Netlify Drop**: открой https://app.netlify.com/drop и перетащи туда папку. Через минуту будет https-ссылка.
- **GitHub Pages**: залей папку в репозиторий, в Settings → Pages выбери ветку `main` и корень.
- **Cloudflare Pages** или **Vercel**: так же, как статический сайт без сборки.

Папка `concepts/` к приложению не относится. Если не хочешь её публиковать, не клади её в выкладку.

Дальше на телефоне:

- **Android, Chrome**: открой ссылку. Появится карточка «Поставь „Остров“ на экран „Домой“» или пункт «Установить приложение» в меню Chrome.
- **iPhone, Safari**: «Поделиться» → «На экран „Домой“» → «Добавить». В приложении есть подсказка с этими шагами.

После первого открытия всё лежит в кеше телефона, и остров работает в самолёте.

## Как выпустить обновление

Поменяй `VERSION` в `sw.js` (например, `ostrov-v2`), закоммить и сделай `git push`. GitHub Pages обновится за минуту-две, а телефоны скачают новую версию в фоне и покажут её при следующем запуске.

Если добавляешь новый файл, который нужен приложению, впиши его в список `SHELL` в `sw.js`.

## Что внутри

- `index.html` — каркас, манифест, иконки, мета-теги для iPhone, регистрация service worker.
- `app.js` — экраны (Сегодня, Сезон, Остров, Летопись), примерные данные и механики: опыт S/M/L, сферы, которые зарастают и оживают, босс сезона, быстрая запись своими словами, возвращение после перерыва. Из GTD: входящие с разбором, список «Потом» и подбор дела «Сейчас» по силам и времени. Плюс установка на телефон и ярлыки с иконки.
- `island.js` — процедурный low-poly остров на three.js. Не рисует, когда остров не виден, чтобы беречь батарею.
- `styles.css` — дизайн-токены, светлая и тёмная темы, четыре неба, раскладка для телефона и альбомной ориентации.
- `sw.js` — офлайн-кеш приложения.
- `manifest.webmanifest` — имя, иконки, цвета, ярлыки «Записать мысль» и «Входящие».
- `vendor/three.module.min.js` — three.js r165 (MIT).
- `fonts/` — Onest и Unbounded (SIL Open Font License 1.1).
- `icons/` — иконка в SVG и PNG для Android, iPhone и браузера.

Прогресс хранится в памяти браузера на этом устройстве. У установленного приложения на iPhone своя память, отдельная от Safari. Кнопка «Сбросить прогресс» в панели «Демо» возвращает пример к началу.
